# MokoFile

Нативный файловый менеджер для Android в стиле **Material You** (Material 3, dynamic color из обоев).
Написан на **Java** без WebView. Минимальная версия — Android 10 (API 29), целевая — Android 15 (API 35).

## Возможности v0.1.0

- Навигация по файловой системе, хлебные крошки, история переходов
- Список и сетка, сортировка по имени / размеру / дате / типу
- Быстрые фильтры: Все, Фото, Видео, Музыка, APK
- Поиск по текущей папке
- Мультивыделение: копировать, вырезать, вставить, удалить
- Переименование, создание папки, импорт файлов
- Открытие файлов, «Поделиться», сведения об объекте
- Карточка занятого места во внутренней памяти
- Светлая / тёмная / системная тема, динамическая палитра Material You
- Экран настроек: тема, динамический цвет, вид по умолчанию, скрытые файлы,
  «сначала папки», подтверждение удаления, состояние доступа к хранилищу и сброс настроек

## Сборка

Требуется JDK 17 и Android SDK (platform 35, build-tools 35.0.0).

```bash
./gradlew assembleDebug
```

APK появится в `app/build/outputs/apk/debug/MokoFile-0.1.0-debug.apk`.
Чтобы сразу положить его в общую папку сборок:

```bash
./gradlew exportDebugApk
```

Тогда APK окажется в `../builds/MokoFile-0.1.0-debug.apk` (то есть `nichevo/builds`).

## Разрешения

Приложению нужен `MANAGE_EXTERNAL_STORAGE` («Доступ ко всем файлам»).
При первом запуске MokoFile открывает системный экран, где нужно включить этот доступ.
Для установки APK из файла требуется разрешение «Установка неизвестных приложений».

## CI

Workflow `.github/workflows/build.yml` собирает debug APK на каждый push в `main`/`master`
и выкладывает его артефактом `MokoFile-debug`.
